# PoolAim Pro Max

تطبيق Android لمساعدة لاعبي البلياردو في حساب أفضل ضربة بكرات 8-ball اعتمادًا على صورة واحدة للطاولة — يعمل على لقطات شاشة 8 Ball Pool والصور الحقيقية معًا.

## المعمارية

- **Kotlin + Jetpack Compose (Material 3)** مع MVVM وفصل منظم للطبقات
- **minSdk 26 / targetSdk 35**
- **OpenCV** (`org.opencv:opencv:4.10.0`) لكشف الطاولة والكرات محليًا
- **DataStore** للإعدادات، **Room** للتاريخ
- موارد عربية وإنجليزية مع `supportsRtl`؛ التعريب والإنجليزية غير مكتملين
- Coroutines + Dispatchers.Default لأحمال الرؤية الحاسوبية

## نتيجة مراجعة المصدر

هذا إصدار **0.3.0-alpha تجريبي**، وليس تنفيذًا مكتملًا للبرومبت الهندسي. نجاح بناء APK لا يثبت صحة الكشف أو مطابقة الحسابات للصورة.

| المرحلة الأصلية | الحالة الفعلية في المصدر |
|---|---|
| A — الاستيراد والمجموعة | Photo Picker واختيار المجموعة موجودان؛ ACTION_SEND معلن في Manifest دون معالجة في Activity. استعادة الحالة والصلاحيات طويلة الأجل غير مكتملتين. |
| B — الطاولة والمعايرة | كاشف حدود ومعايرة يدوية أوليان؛ توجد اختلافات بين الإحداثيات الأصلية والمصغرة والمطبّعة. الجيوب مفترضة هندسيًا وليست مكتشفة. |
| C — الكرات والمراجعة | HoughCircles وتصنيف لوني مبدئي؛ لا توجد أدوات تعديل الكرات أو معرفات ثابتة أو ثقة لكل كرة. |
| D — الفيزياء والترتيب | ضربات مباشرة وكرة شبحية وفحص عوائق مبدئي؛ لا ارتدادات أو سلاسل تصادم. المسارات المسدودة تبقى في القائمة. |
| E — AimBoard | تراكب بسيط واختيار ضربة؛ إسقاط تقريبي، دون التكبير الدقيق أو التراجع والإعادة أو ضبط الزاوية. |
| F — المحاكاة والمساعد | غير منفّذين. |
| G — التدريب والسجل والإحصاءات | Room وشاشة سجل أولية؛ لا مدخل تنقل للسجل ولا استعادة موصولة. التدريب والإحصاءات غير منفّذين. |
| H — التحقق والتسليم | اختبارات وحدة محدودة؛ لم تثبت دقة الكشف أو زمن المعالجة أو التوافق على أجهزة Android. |

## تدفق الاستخدام الموجود

مجموعة اللاعب → اختيار صورة → كشف الطاولة → كشف الكرات → قائمة ضربات مباشرة. زر الإنهاء يطلب الحفظ ثم يغلق Activity؛ اكتمال الحفظ غير مضمون لأن العملية مرتبطة بنطاق الواجهة.

## قيود مهمة قبل الاستخدام

- لا تعتمد على خطوط التصويب للدقة: أبعاد الصورة والمعايرة ومساحة الكشف وإسقاط التراكب غير موحدة بالكامل.
- أرقام الكرات غير معروفة، ولا توجد مراجعة يدوية لتصحيح التصنيف حاليًا.
- خيار كرة 8 والمجموعة المخصصة يحتاجان تصحيح تصفية الأهداف؛ الكرات غير المؤكدة تدخل مجموعة اللاعب دون تأكيد.
- درجة الضربة **هندسية تقريبية** وليست احتمال نجاح إحصائي. لا توجد قياسات تؤكد دقة بكسل واحد أو زمن أقل من 500ms.
- بيانات الصورة قد تصبح غير متاحة لاحقًا؛ لم يُنفّذ نسخ داخلي مضمون للصور ذات الصلاحيات المؤقتة.
- لا توجد نسخة Release موقعة بمفتاح نشر خاص بالمستخدم. نسخة Debug للتجربة فقط.

## البناء المحلي

```bash
git clone https://github.com/dorking1/poolaim-pro-max.git
cd poolaim-pro-max
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew test   # اختبارات الوحدة
```

يتطلب JDK 17 وAndroid SDK (يُدار تلقائيًا عبر Android Studio).
