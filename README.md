# PoolAim Pro Max

تطبيق Android لمساعدة لاعبي البلياردو في حساب أفضل ضربة بكرات 8-ball اعتمادًا على صورة واحدة للطاولة — يعمل على لقطات شاشة 8 Ball Pool والصور الحقيقية معًا.

## المعمارية

- **Kotlin + Jetpack Compose (Material 3)** مع MVVM وفصل منظم للطبقات
- **minSdk 26 / targetSdk 35**
- **OpenCV** (com.quickbirdstudios:opencv 4.10) لكشف الطاولة والكرات
- **DataStore** للإعدادات، **Room** للتاريخ
- دعم كامل للعربية (RTL) والإنجليزية
- Coroutines + Dispatchers.Default لأحمال الرؤية الحاسوبية

## المراحل

| المرحلة | النطاق | الحالة |

## تدفق الاستخدام

مجموعة اللاعب → استيراد صورة → كشف الطاولة (يدوي عند الفشل) → كشف الكرات → خطة الضربة (اختر من القائمة لعرضها) → حفظ تلقائي في السجل.

## قيود معروفة (شفافية)

- أرقام الكرات (1–15) غير معروفة بعد (تحتاج OCR — مخطط لاحقًا).
- تصنيف مصمتة/مخططة عبر التشبع يعمل جيدًا على لقطات اللعبة؛ الصور الحقيقية بإضاءة ضعيفة قد تعطي UNKNOWN قابلة للتصحيح.
- درجة الضربة **هندسية بحتة** وليست احتمال نجاح إحصائي (النموذج غير معايَر ببيانات تجريبية).

## البناء المحلي

```bash
git clone https://github.com/dorking1/poolaim-pro-max.git
cd poolaim-pro-max
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew test   # اختبارات الوحدة
```

يتطلب JDK 17 وAndroid SDK (يُدار تلقائيًا عبر Android Studio).

## البناء السحابي

بعد إضافة `.github/workflows/build-apk.yml` يدويًا (أداة الرفع الآلية محجوبة لمسارات `.github/`)، يُبنى APK تلقائيًا مع كل دفعة ويُحمّل من صفحة Actions.
